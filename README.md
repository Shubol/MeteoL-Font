# MeteoL-Font
**Most commonly used mereological symbols in the SHMÚ packed into an easy-to-use TrueType font.**
I created it for myself, but maybe it will help someone.<br/>It is quite possible that there will be errors or you will need to add something. In such a case, do not hesitate to create a fork or contact me.

**MeteoL.ttf** - font file ready for installation.<br/>**MeteoL-character map.ods** - Character map and examples of symbol combinations.

**MeteoL.svg** - Inkscape document containing all symbols. You need to edit this if you want to add or modify symbols.<br/>**MeteoL.sfd** and **MeteoL.g2n** - meta files generated by Font Forge.

## Installation:
Double-clicking on MeteoL.ttf should open Font Viewer on most systems. Then click the "Install" button. Done.

## Editing and adding:
* Create a New Fork on GitHub.
* Download everything from the /src directory.
* Open MeteoL.svg in Inkscape.
* Use "SVG Font Editor" tool in Inkscape.
* Save as an Inkscape .svg document.
* Open MeteoL.sfd in Font Forge and import the updated MeteoL.svg.
* In "Elements" - "Font Info" - "PS Names" change the version. For example, if you are adding symbols, then from 1.1 to 2.0. If you are fixing bugs, then from 1.1 to 1.2.
* File - Generate Fonts - to generate the necessary files. There are "a few" errors. I admit I haven't studied them at all. On Linux Mint and  LibreOffice, they doesn't cause any problems.
* Save the MeteoL.sfd project.
* Upload **everything** to your Fork.
* Submit for approval via "Pull Request"

Tested on Linux Mint and LibreOffice.
